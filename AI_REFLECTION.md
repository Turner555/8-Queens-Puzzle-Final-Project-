# AI Reflection
Throughout my project, I used AI selectively to help me refine and understand concepts that were causing errors in my code, particularly when dealing with newer concepts.

To start, when implementing the backtracking algorithm in my `possible_placements` function, I tried making a separate list of placements to recurse through and check all of the possible outcomes. While my code backtracked throughout this list, I needed to be backtracking through the list originally passed into the function call to correctly provide the possible outcomes. After struggling to identify the issue, I used AI to help me understand why I was getting an unexpected output. It advised me to backtrack through the original list instead of a copy, which helped me to get the desired output from my function. Additionally, to help me understand why my original method was not working properly and why it was better to directly backtrack through the original list, I had it walk me through a step-by-step visualization of what was going on behind the scenes of my function.

Furthermore, I also encountered issues when implementing ANSI escape codes for the coloring of the board in `board.py`. While I used online resources like GitHub to understand what the code meant and what colors and designs I could implement, it would not change the color of my board when I tried to implement it into my program. I asked AI why I might be having issues and it pointed out that I had forgotten to include the reset code, causing my code to not display any colors. After adding in the reset code my program printed the colors as desired.

Additionally, when running my implementation of regular expressions in `input_check.py`, I kept running into an error saying that my function was trying to split `None`. I asked AI why this might be happening and it pointed out that while my code was running correctly, I was recursing without returning the recursive call, causing my final return to be `None` if the user did not input a valid answer on the first attempt. Aside from minor advice on coding mistakes, I ended my project by asking AI to give my program a stress test in order to find any edge cases that may cause it to crash.

Overall, I used AI as a tool to help diagnose and give me advice on issues and gain a deeper understanding of what is going on behind the scenes. However, I also realized how careful you must be when using AI. I often asked it for advice on an issue and received advice that did not solve the issue or caused other parts of my program to crash. AI is a great tool for aiding you in the process of designing complex codes, however, its advice should not be taken as absolute. Instead, it requires a careful consideration and understanding by the programmer of what is going on in the code and what AI is suggesting and then deciding how to use those suggestions and adapt them into their code. To ensure the code I submitted was my own, I instructed AI to diagnose issues without giving me code and then gave careful consideration as to how I might resolve that issue in my program. In doing so, I was able to produce code that is both genuine and accurate.
